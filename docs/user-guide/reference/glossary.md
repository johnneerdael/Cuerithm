# Glossary

<p class="lead">Plain definitions of the words CueRithm uses, in alphabetical order, each with a link to the page where the word matters. Look a term up in under a minute.</p>

!!! tip "New to this?"
    If you are meeting these words for the first time, read [Prepare your first tracks](../get-started/first-tracks.md) first. Most terms make sense after one run through it.

The products named here (Beatport, Traxsource, rekordbox, Mixxx and the others) belong to their makers. CueRithm is independent software and is not affiliated with any of them.

## A to C { #a-c }

| Term | Meaning | Learn more |
|---|---|---|
| **Analysis** | CueRithm's measurement of a track's key, BPM, beatgrid, energy and cues. It runs on your computer and needs no internet. | [How does CueRithm analyse a track?](../how-it-works/pipeline.md) |
| **Analyze again** | The command that prepares a finished track again with today's settings. It is the only way finished results change. | [Analyze a track again](../analysis/analyze-again.md) |
| **Archive** | A view that holds tracks you no longer play. Archiving takes a track out of Tracks and playlists but keeps its analysis and cues, and the audio file stays where it is. | [Archive tracks you no longer play](../files/archive.md) |
| **Atomic swap** | Replacing a file in one step, so you always have either the old file or the new one and never a half-written one. | [How are tags written safely?](../how-it-works/tag-writing.md) |
| **Automatic Smart Playlists** | The sidebar folder where CueRithm keeps the smart playlists it builds for you by artist, BPM range, release month, genre and key. | [Smart Playlists settings](settings/smart-playlists.md) |
| **Automatic tagging** | Looking up each new track in online catalogs and writing the tags you chose. It is off until you switch it on. | [Tag new tracks from Beatport and Traxsource](../tagging/tag-new-tracks-automatically.md) |
| **Beatgrid** | The row of beat positions for a track, set by its BPM and the position of its first beat. Cues and the player's beat lines sit on it. | [Check the beatgrid at beat level](../analysis/check-the-beatgrid.md) |
| **Breakdown** | A cue for the part of a track where the energy falls away after a drop. | [Cue names, letters and colours](cue-types.md) |
| **BPM** | Beats per minute: the tempo of the track as CueRithm measured it. | [Read a track's key, BPM and energy](../analysis/read-key-bpm-energy.md) |
| **Camelot key** | A key written as a number from 1 to 12 and a letter, A for minor and B for major, so that neighbouring keys mix well. | [Understand Camelot keys](../analysis/camelot-keys.md) |
| **Catalog match** | A recording in an online catalog that CueRithm judges to be the same as your track. | [How does catalog matching work?](../how-it-works/matching.md) |
| **Category** | A named group of your own custom tags, such as "Mood", that you apply to tracks in Curate. | [Group tracks with categories and custom tags](../tagging/curate-tracks.md) |
| **Cleanup** | Rules that tidy human-readable tags such as titles, genres and artists, without touching audio or analysis. | [Clean up messy titles, genres and artists](../tagging/cleanup-messy-titles.md) |
| **Cloudflare solver** | An optional program you run that lets CueRithm get past a catalog site's Cloudflare check. | [Get past a Cloudflare block](../tagging/cloudflare-solver.md) |
| **Combine providers** | A tagging setting that applies matches from every selected provider in order, instead of stopping at the first. | [Automatic tagging settings](settings/automatic-tagging.md#master) |
| **Compatible tracks** | A tool that lists the tracks in your library that mix with a chosen one, by key, BPM and energy. | [Find tracks that mix with the one playing](../playlists/find-compatible-tracks.md) |
| **Cue** | A named, coloured position in a track that you can jump to. CueRithm's cues carry no energy value. | [Cue names, letters and colours](cue-types.md) |
| **Cue template** | A saved cue layout you can apply to many tracks at once. | [Reuse one cue layout on many tracks](../analysis/corrections/cue-templates.md) |
| **Curate** | The panel where you rate tracks, write notes and apply custom tags and categories. | [Group tracks with categories and custom tags](../tagging/curate-tracks.md) |
| **Custom tag** | A label you make yourself and group into a category. Custom tags live in CueRithm's library, not in the file. | [Group tracks with categories and custom tags](../tagging/curate-tracks.md) |

## D to L { #d-l }

| Term | Meaning | Learn more |
|---|---|---|
| **Decoder** | The component, bundled with CueRithm, that turns an audio file into the sound data that analysis reads. | [How are audio files decoded?](../how-it-works/decoding.md) |
| **Donor** | In a duplicate merge, the track whose tags, cues and grid are copied onto the keeper. | [Find and merge duplicate tracks](../files/library/find-duplicates.md) |
| **Drop** | A cue for the point where the full-energy part of a track first begins. | [Cue names, letters and colours](cue-types.md) |
| **Duplicate group** | Tracks that the duplicate scan thinks are the same recording, shown together for review. | [Find and merge duplicate tracks](../files/library/find-duplicates.md) |
| **Edit cues & grid** | The button in the player that opens the controls for correcting cues, loops and the beatgrid. | [Fix a wrong cue, loop or beatgrid](../analysis/corrections/index.md) |
| **Energy** | One whole-track rating from 1 to 10 for how intense a track is. There is no energy for a section or a cue. | [How is energy rated?](../how-it-works/energy.md) |
| **Fingerprint** | A compact signature of a track's sound, made on your computer and sent, without any audio, to identify a recording that has no catalog match. | [Identify a track with no match](../tagging/identify-unknown-tracks.md) |
| **Folder (playlist folder)** | A sidebar item that holds playlists, so you can group them. | [Group playlists in folders and reorder them](../playlists/organize-playlists.md) |
| **Fuzzy** | A key-matching mode that accepts the same number and one step either way, with either letter. | [Library preferences](settings/library.md#key-modes) |
| **Harmonic** | The default key-matching mode: the same key, one step either way on the same letter, or the relative major or minor. | [Library preferences](settings/library.md#key-modes) |
| **Hot cue** | A cue that DJ software can trigger from a pad. CueRithm's structural cues are hot cues, and the S.O.S. loop is a loop. | [Cue names, letters and colours](cue-types.md) |
| **Incoming** | The view where new tracks are prepared. A track stays here until preparation succeeds, then moves to Tracks. | [Follow a track through Incoming](../files/follow-incoming.md) |
| **Keeper** | In a duplicate merge, the track you keep. The others are archived. | [Find and merge duplicate tracks](../files/library/find-duplicates.md) |
| **Key** | The musical key CueRithm measured for a track, shown in Camelot notation. | [Read a track's key, BPM and energy](../analysis/read-key-bpm-energy.md) |
| **Library** | Everything CueRithm knows about your tracks: results, cues, playlists and settings. It is kept in CueRithm's own database; your audio stays in your folders. | [Where CueRithm keeps your data](../files/library/where-data-lives.md) |
| **Library backup** | A saved copy of the library's data that you can restore later. It does not copy your music. | [Back up your library](../files/library/back-up-library.md) |
| **Library time zone** | The time zone smart playlists use to decide which day a date falls on. | [Library preferences](settings/library.md#controls) |
| **Loop** | A section of a track between two times that repeats when played. CueRithm can add a 16-beat S.O.S. loop. | [Set a loop](../analysis/corrections/set-loops.md) |

## M to R { #m-r }

| Term | Meaning | Learn more |
|---|---|---|
| **Maintenance** | The sidebar tool that finds duplicates, missing or broken files and unused files. | [Look after your library](../files/library/index.md) |
| **Memory cue** | A cue type some DJ software keeps apart from the hot cue pads. CueRithm's own cues are never memory cues. | [Smart playlist fields and operators](smart-playlist-fields.md) |
| **Needs attention** | The state of a track whose preparation stopped on an error. It waits in Incoming with the reason. | [Fix a track that needs attention](../files/needs-attention.md) |
| **OneTagger** | The open-source tagger that CueRithm's catalog tagging is built on. | [Credits and open source](../help/about/credits.md) |
| **Ordinary playlist** | A playlist you fill and order by hand, as opposed to a smart playlist. | [Create a playlist and add tracks](../playlists/create-a-playlist.md) |
| **Organize files** | The tool, and the setting, that renames, moves or copies files by a naming pattern. | [Rename and sort files into folders](../rename/organize-files.md) |
| **Overwrite** | A tagging choice that lets a catalog value replace the value already in the file. | [Automatic tagging settings](settings/automatic-tagging.md#fields) |
| **Pioneer USB** | A USB drive prepared with your library for Pioneer players. | [Prepare a Pioneer USB stick](../sync/pioneer-usb.md) |
| **Playlist flow** | A view that charts how a playlist moves in key, BPM and energy from track to track. | [Check the flow of a playlist](../playlists/check-playlist-flow.md) |
| **Preparation** | What CueRithm does to a new track: decode, analyse, tag and clean up if switched on, rename if set, and place cues. | [Follow a track through Incoming](../files/follow-incoming.md) |
| **Preparation preset** | A named bundle of cue, tagging, cleanup and naming rules that a watch folder can use. | [Save your setup as a preset](../files/presets.md) |
| **Provider** | An online catalog or lookup service that automatic tagging asks, such as Beatport or Traxsource. | [Choose providers and fields to write](../tagging/choose-providers.md) |
| **Ready** | A track whose preparation finished completely. Ready tracks are in Tracks. | [Status icons and job states](status-icons.md) |
| **Recovery backup** | A copy of a file that CueRithm holds while it writes tags, so an interrupted write can be rolled back. It is deleted when the write has settled. Undo uses recorded tag values instead. | [Undo a tag change](../tagging/tag-history.md) |
| **Regular expression** | A pattern language for matching text. Smart playlists use the JavaScript flavour. | [Smart playlist fields and operators](smart-playlist-fields.md#cmp-regex) |
| **Release (match a folder as a release)** | A single album or EP in a catalog. CueRithm can match a whole folder to one release. | [Match a folder as a release](../tagging/match-a-release.md) |
| **rekordbox** | DJ software that CueRithm can write to directly, on compatible 6 and 7 builds. | [Sync to rekordbox 6 or 7](../sync/rekordbox-direct.md), [Check what works with your DJ software](../help/compatibility.md) |

## S to Z { #s-z }

| Term | Meaning | Learn more |
|---|---|---|
| **S.O.S. loop** | The optional 16-beat emergency loop CueRithm adds in a steady late section. | [Cue names, letters and colours](cue-types.md) |
| **Slot** | The numbered position of a cue, shown as a letter: A for the first. | [Cue names, letters and colours](cue-types.md#letters) |
| **Smart Fix** | One cleanup rule from the ordered list, such as Casing or Number prefix. | [Cleanup settings](settings/cleanup.md#smart-fixes) |
| **Smart playlist** | A playlist defined by conditions instead of a hand-picked list. It updates itself as your library changes. | [Build a smart playlist](../playlists/build-a-smart-playlist.md) |
| **Staged copy** | A temporary copy of a file where tag changes are written and checked before they replace the original. | [How are tags written safely?](../how-it-works/tag-writing.md) |
| **Structural cue** | A cue placed by analysing the shape of a track: Start, Drop, Breakdown, Drop #2, Breakdown #2 and End / Fade-out. | [Cue names, letters and colours](cue-types.md) |
| **Sync** | Sending playlists, tracks, cues and grids from CueRithm to DJ software. | [Send your library to DJ software](../sync/index.md) |
| **Sync destination** | The DJ program or drive you sync to: rekordbox, Pioneer USB, VirtualDJ, Mixxx, Engine DJ, djay Pro or Serato DJ Pro. | [Send your library to DJ software](../sync/index.md) |
| **Tracklist matcher** | A tool that rebuilds a set as a playlist from a typed or pasted tracklist. | [Rebuild a set from a tracklist](../playlists/match-a-tracklist.md) |
| **Tracks** | The main view: every ready track that is not archived. | [Find a track: search, sort and filter](../analysis/find-tracks.md) |
| **Watch folder** | A folder CueRithm checks for new music and prepares automatically. | [Keep a folder like Beatport in your library](../files/watch-folders.md) |
| **Waveform** | The picture of a track's loudness over time, coloured by bass, mids and highs. | [How is the waveform drawn?](../how-it-works/waveform.md) |
| **Waveform style** | The colour scheme used for waveforms. | [Choose a waveform style](../customize/waveform-style.md) |
